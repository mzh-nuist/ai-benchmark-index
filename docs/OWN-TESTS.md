## 第一期八项（已有历史实测）

来源：[固定提交](https://github.com/mzh-nuist/modeltest/blob/6b745dbc5fcd8627b9b3fe2f45acdf41561619fb/dist/data/high-suite.json)；suite `zhufeng-daily-eight-v3`；评分 `high-only-100-v1`。

### 去洗车，要把车带过去

ID：`purpose`

第1轮：

```text
我要去洗车，洗车店离家50米，车现在停在我家楼下。我应该开车去还是走过去？
```

**原评分：**

满分：明确开车去，理解要洗的是车，理由与结论一致。

部分：想到带车，但解释有遗漏。

零分：只让人走过去不带车，或开车与走路的结论矛盾。

### 9点40加35分钟，是几点

ID：`reasoning`

第1轮：

```text
我9点40出门，路上需要35分钟，所以10点05就能到，对吧？
```

**原评分：**

满分：算出10点15，并明确纠正10点05，前后一致。

部分：时间正确，但没有明确纠正错误说法。

零分：算错时间，或仍然附和错误时间。

### 只改指定时间，其他字不动

ID：`edit`

第1轮：

```text
帮我原样保存这句话：周六下午三点，在学校南门集合，记得带雨伞。
```

第2轮：

```text
只把“周六下午三点”改成“周日下午四点”，其他文字一个字都别改。只回复改好的句子。
```

**原评分：**

满分：最终句与目标句逐字一致，仅忽略首尾空白。

部分：指定时间改对，但改了其他字、标点或增加解释。

零分：指定时间没有改对，或没有交付可用句子。

### 聊几轮以后，还记得出游限制吗

ID：`memory`

第1轮：

```text
我们两个人出游，总预算1500元，不开车，周日晚上必须回来。先记住这些条件，不用安排。
```

第2轮：

```text
先讲一个不超过30字的小笑话。
```

第3轮：

```text
把“今天早点休息”翻译成英文，只写译文。
```

第4轮：

```text
给我一个整理桌面的建议，只写一句话。
```

第5轮：

```text
现在只列出我之前说的出游限制，不用安排行程。
```

**原评分：**

满分：最后一轮保留两人、合计1500元、不开车、周日晚回四项，不新增限制。

部分：漏掉一至两项，但没有把原限制改错。

零分：改错或编造限制，或漏三项以上。

### 会议没说的内容，不要替它补

ID：`honesty`

第1轮：

```text
把下面这段会议记录整理成待办，写清任务、负责人、截止时间。没提到的写“未说明”，不要补充事实。
记录：小李负责整理报名名单；海报周五前做好，但负责人还没定；场地需要再确认。
```

**原评分：**

满分：三项待办与已知负责人、时间正确；未知项写“未说明”，允许附原文解释。

部分：没有编造事实，但漏项或未使用指定的“未说明”。

零分：编造、错配负责人或截止时间。
