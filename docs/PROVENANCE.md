# 来源、状态与复用边界

本索引合并两个工作流：已有 ModelTest 题库与网站维护，以及「寻找好玩又测智能的AI测评」中的长期选题研究。只发布可公开的题目、归纳和外部链接，不发布聊天全文、私人协作者信息、账号配置、余额或原始API日志。

自己的题目从公开 `mzh-nuist/modeltest` 仓库当前提交导出；固定提交和文件 SHA-256 见 [data/modeltest-tasks.json](../data/modeltest-tasks.json)。导出只选择公开任务字段，未读取 `private/` 或 `results/` 中的模型原始记录。已采集状态表示旧项目有公开证据，不代表本索引运行了模型，更不是目前所有接口仍可用的保证。

外部项目保留原作者入口。`reviewed-primary` 表示本轮核读过原始页面；`historical-lead` 表示另一对话中的来源线索、本轮未重新核读，可能已变化；`original-proposal` 表示讨论中的原创中文方案，未形成正式运行器。来源日期、发现日期、核验日期不混用。GitHub/API连通性检测只证明页面存在，不能把 HTTP 200 当成题面、许可和复现能力都通过验收。

回归适用性为编辑建议：`priority` 优先构建固定变体回归集；`supporting` 辅助观察或专项；`exclude` 不用于核心降智结论。所有标记都需要结合固定版本和重复测试解读。

核心收录遵守[贡献指南](../CONTRIBUTING.md)：仅能力评测集、回归题库与评测执行／检查脚本。创意、一般方法框架和未核实入口迁入[候补文档](IDEAS.md)，不再因为来自历史对话就自动进入核心索引。
