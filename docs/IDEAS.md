# 原创改编与候补

以下是讨论里提出的方案，**尚未在本索引实现，也没有本轮模型实测**。它们与成熟基准、已接站题目分开记录。

| 方案 | 题意与可核验目标 | 还缺什么 |
| --- | --- | --- |
| AI传话事故 | 预先给定角色、动作、物品、因果；逐棒看图转文／文转图，核对保留和新增事实 | 固定事实表、各棒接口、盲评与多次采样；不能把其中一个模型的失败归给整条链路 |
| 鹈鹕修车厂 | 所有模型看到同一张脚悬空的坏图，只修指定连接，保护无关结构 | 统一坏图、局部连接量表、安全渲染、前后差异检查 |
| 外星厕所 | 隐藏开门规则，模型可试验、观察反馈，再迁移到新关卡 | 借鉴 WitnessBench；厕所只是原创包装，须实现规则引擎 |
| 抓摸鱼鹈鹕 | 复杂画面找同时满足帽子、鞋子、物品条件的目标，也放目标不存在的图 | 借鉴 WaldoBench；原创场景、目标框、无目标判据 |
| 羊圈开门对照 | 仅打开一个缺口，羊数量不变，重新判断逃生 | 借鉴 MindTopo；清晰几何、连通真值、避免缺口太小 |
| 三选一放球 | 从三个固定位置释放球，选出唯一能稳定触发目标接触的方案 | 借鉴 PHYRE；离线模拟三个答案，排除数值不稳定场景 |
| 非传递骰子公司 | A=[2,2,4,4,9,9]，B=[1,1,6,6,8,8]，C=[3,3,5,5,7,7]，对手先选，求后手最优骰 | 示例C胜A、A胜B、B胜C，均5/9；正式需生成新骰面并枚举验算 |
| 烤肉切片加题 | 肉柱旋转，切片后肉柱变薄，盘里新增一片，不能凭空长回去 | 原社区动画题的原创扩展；冻结状态、时间点与动作检查 |

吸血鬼送外卖、僵尸赶高铁、外星通缉令、幽灵群聊、办公室谈判等是早期场景方向；狼人排班、机器人维修、怪物合租和外星纪要已有独立公开开发题，见 [自有题库](OWN-TESTS.md)。相似想法不重复包装为多个成熟 benchmark。

SpaceChem 仅保留为候补：长期工厂／编程规划和本站短题目标不同，另一对话未能充分打开原站，本轮没有运行或核验其成绩。来源入口见总索引。
